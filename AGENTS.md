## 1. Mission & Project Identity
You are an autonomous AI game engineering agent building **Namma Auto: Chennai Rickshaw Simulator 3D**, a culturally authentic, 60 FPS Android driving and auto-rickshaw economic simulator set in Chennai, Tamil Nadu, India.

* **Target Platform:** **Android only** (Google Play). Do not add iOS, desktop or web export presets, plugins or code paths.
* **Target Engine:** Godot Engine **4.4.1** (pinned in CI), `mobile` renderer with OpenGL ES 3 fallback, **Jolt Physics 3D**.
* **Primary Language:** Statically-typed **GDScript 2.0** (strict typing enforced on all variables, parameters, and return types).
* **Target Hardware Baseline:** Budget Indian Android smartphones (MediaTek Helio G85 / Snapdragon 680, 3 GB–4 GB RAM, OpenGL ES 3.0 / Vulkan 1.1, 60 FPS target, <85 MB initial download).

## 3. Non-Negotiable Architectural Rules for AI Agents

### Rule 1: Strict Decoupling via `SignalBus.gd`
* **FORBIDDEN:** brittle cross-subsystem paths such as `get_node("../../UI/TouchHUD/Speedometer")`.
* **REQUIRED:** emit and connect typed signals through `SignalBus` (e.g. `SignalBus.speed_updated.emit(kmh)`, `SignalBus.horn_blasted.emit(pos, fwd, radius, tier)`).
* **Input:** touch controls press InputMap actions (`Input.action_press`). Gameplay code reads actions only, so keyboard, touch and tests drive the game identically.

### Rule 2: 100% Static Typing in GDScript
* Every variable, array, dictionary, argument and return value has an explicit type. `untyped_declaration` is set to **Error** in `project.godot`.

### Rule 3: Plain-Text Scene & Resource Hygiene (`.tscn` / `.tres`)
* Never invent `uid://` values when hand-writing `.tscn`/`.tres`; omit `uid=` and let Godot assign. Commit the generated `*.uid` and `*.import` files.
* All tunable gameplay numbers live in `.tres` resources, never in physics code.

### Rule 4: Delta-Trike (3-Wheel) Physics Fidelity
* Never use a 4-wheel template. **1 front centre steerable wheel** (`max_steer_angle_deg = 45.0`) and **2 rear drive wheels**, rear-biased `center_of_mass_offset = Vector3(0.0, -0.25, 0.35)`.
* 3-point `RayCast3D` suspension with anti-roll stabilisation; `12°–18°` roll on two wheels = **"Two-Wheel Side-Tilt Gethu"**.

### Rule 5: Mobile Performance Guardrails
* ≤ **150 draw calls** per frame; shared materials, ETC2/ASTC, `MultiMeshInstance3D` for static props.
* ≤ **18 pooled AI vehicles** within **120 m** of the player. Never `instantiate()`/`queue_free()` during driving frames.
* Physics at a fixed **60 Hz**. Primitive colliders (`BoxShape3D`, `CapsuleShape3D`) on moving bodies.

### Lessons recorded (do not regress)
* Pooled `AnimatableBody3D` traffic must be teleported with its collision shape **disabled** and re-enabled the next tick. Teleporting with collision on made Jolt launch the player auto at ~260 m/s.
* Apply longitudinal (drive/brake) wheel forces at **CoM height**; at contact height the trike wheelies.
* Directional shadows use **orthogonal (1 split)**, ≤ 45 m; flat ground meshes don't cast. PSSM-4 cost ~66 draw calls on the greybox alone.
* World flat layers: ground plane at y = -0.15, areas -0.08…-0.02, sidewalks/roads +0.045…+0.08, camera near = 0.1. Closer spacing z-fights from the air.
* Vertex-coloured materials need `vertex_color_is_srgb = true`; sky ambient + bright fog clipped the city to white in the compatibility renderer, so use colour ambient.
* Godot only exports non-resource files listed in `include_filter` — `data/world/*` must stay in `export_presets.cfg` or the APK ships without a map.
* Traffic on the graph uses `Basis.looking_at(travel_dir)`; keep `Array.filter()` results out of typed arrays (it returns untyped `Array`).
* HUD: add all panels before all labels (separate `Panels`/`Texts` layers) and skip outlines on text that sits on a panel. Interleaving them cost ~20 extra 2D draw calls.
* The road graph must be **strongly** connected for GPS: `build_world.py` opens map-edge one-ways both ways; don't remove that step.
* Late listeners read `SignalBus.current_road_graph`; `road_graph_ready` fires deferred once.
* Test runs never touch the player's save: GameState disables persistence when the scene arg starts with `res://tests/`. Use `GameState.reset_profile()` between test cases.
* Effective vehicle stats always come from `GameState.active_stats()` (a fresh duplicate); never mutate the `.tres` at runtime.
* No emoji in UI strings — the default font has no emoji glyphs; Tamil comes from the bundled Noto Sans Tamil fallback.
* UI text goes through `tr("KEY")` with keys in `translations/ui.csv`; rider dialogue stays Tanglish.
* Wheel rays start **below** the chassis origin so the CoM offset sits ~0.55 m above the road; otherwise the auto can never lean.
* The map is **real size (1 : 1)**, ~7 × 6 km around the origin. Jolt clips `WorldBoundaryShape3D` to `physics/jolt_physics_3d/limits/world_boundary_shape_size` (default 2 km): keep it at 20 km in `project.godot` or the auto falls through the ground away from the origin.
* Road surfaces are pre-triangulated in Python (`tools/osm/streets.py`, mapbox-earcut) from osm2streets; the game only copies arrays into one `ArrayMesh` per chunk. Don't triangulate road polygons at runtime. Lane arrows (540k polygons) are deliberately skipped — use decals.
* The road graph takes lane counts/widths from osm2streets (`streets.way_lanes()`), so traffic sits in the drawn lanes. If you change one, rebuild both (`build_world.py`).
* Building walls collide through **one** `ConcavePolygonShape3D` per chunk (static only). Don't go back to a box per building.
* Kick-start rhythm and other timing use accumulated physics time, never `Time.get_ticks_msec()`, so tests under `--fixed-fps` stay deterministic.
* Packed arrays read out of a `Dictionary` are **copies**: `(d["v"] as PackedVector3Array).append(x)` silently does nothing. Keep growable buffers as class members (see `WorldChunkStreamer.MeshBuf`).
* `Vector2` is 32-bit: a time window stored in one can round past a `float` "now" (forced rain once stayed off). Pad the start.
* In tests, `await get_tree().physics_frame` resumes **before** nodes' `_physics_process` that frame: wait 2 frames after `Input.action_press` before asserting `is_action_just_pressed` effects.
* Real audio files override the synth automatically when present (`VehicleAudio.stream_or()`); keep the synth fallback so tests and builds never depend on downloads.
* Never gate core play (free roam, Savari, the King Deluxe) behind Driver Level — only cosmetics and the EV.
* `application/config/quit_on_go_back=false`: the Android back button becomes `SignalBus.back_requested` (pause / resume in game, close panel / quit in the menu).

## 4. Closed-Loop Verification Protocol (Run After Every Task)
1. **Import & scene load check:**
   ```bash
   godot --headless --path . --import
   godot --headless --path . --quit-after 120   # must print no SCRIPT ERROR
   ```
2. **Phase test suite** (exit code 0 = pass):
   ```bash
   godot --headless --path . --fixed-fps 60 res://tests/run_phase1_tests.tscn
   godot --headless --path . --fixed-fps 60 res://tests/run_phase2_tests.tscn
   godot --headless --path . --fixed-fps 60 res://tests/run_phase3_tests.tscn
   godot --headless --path . --fixed-fps 60 res://tests/run_phase4_tests.tscn
   godot --headless --path . --fixed-fps 60 res://tests/run_phase5_tests.tscn
   godot --headless --path . --fixed-fps 60 res://tests/run_phase6_tests.tscn
   ```
   After adding a new `class_name`, re-run `--import` first or the runner fails to parse. A parse error leaves the runner idling, so always wrap it in `timeout`.
   Do not use `-s` — autoload globals (`SignalBus`, `GameState`) don't resolve in `-s` scripts. Each new phase adds `tests/run_phaseN_tests.tscn` and a CI step.
3. **Perf probe** (exit 0 = within budget):
   ```bash
   xvfb-run -a godot --path . --rendering-method gl_compatibility --fixed-fps 60 res://tests/run_perf_probe.tscn
   ```
4. **CI:** the **Android Build** workflow (tests + APK export) must be green before a milestone is marked done.
5. **MCP interactive playtest** (when Godot MCP is connected): throttle 4 s → ≥ 35 km/h; full steer at 30 km/h → roll < 22°; horn → AI within 18 m shift sub-lane.
