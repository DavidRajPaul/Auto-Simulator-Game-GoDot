# P0 procedural additions

Auto-panel deformation/scratches, compound wall geometry, ambulance beacon geometry and siren
synthesis are original project code. Existing auto, ambulance and particle asset licences are
unchanged; see the corresponding CREDITS files in models/vehicles, models/traffic and fx.

Map-derived geometry: © OpenStreetMap contributors, ODbL 1.0
(https://www.openstreetmap.org/copyright). Source way IDs remain in data/world/compounds.json.
Segments marked `inferred` are procedural gap separators, not surveyed OSM property boundaries.
