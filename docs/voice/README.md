# Quest voice lines

Voiced dialogue is generated by **Actions -> Generate quest voices** with AI4Bharat
**Indic Parler-TTS** (Apache 2.0: free, commercial use allowed), on the runner's CPU.

1. Write a script here as `SQ<nn>_<Name>_Voice_Script.md`. Each voiced line is one bullet:
   `- sq07_l01 Lakshmi: [tags] Tamil text / [tags] English text`. Text in `[brackets]` is not
   spoken: it picks the emotion (sad, fearful, angry, surprised, happy, commanding,
   conversational). A note in round brackets after the speaker (`Karthik (at Marina):`) is ignored.
2. Every speaker needs a `parler` voice in `tools/voice/cast.json`: a named Parler speaker, a
   description and a fixed seed. The hero is always `Driver` (Raghav, seed 101) and is locked:
   never change his voice, so he sounds the same in every quest. Jaya and Kavitha are the model's
   Tamil speakers; the others are its Indian English speakers reading Tamil.
3. Push. The workflow voices every line that has no file yet and commits
   `assets/audio/voice/<quest>/<id>_<ta|en>.ogg` (mono Vorbis, small). To redo lines, run it by
   hand with their ids in "only". Expect roughly 1-2 minutes per line on the free runner.

Secrets: `HF_TOKEN` (Hugging Face read token for an account that accepted the terms at
huggingface.co/ai4bharat/indic-parler-tts). The `elevenlabs` engine (`pick_voices.py`,
`generate_quest_voices.py`, `voices.json`) is kept for a paid ElevenLabs plan: the free plan
can't use library voices through the API and its output is non-commercial.
